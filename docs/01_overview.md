I have a Freenove ESP32-WROVER board with a button and an RGB light connected on a breadboard with male-to-male jumper wires.

The RGB light connections are:
- Red: GPIO 13
- Green: GPIO 15
- Blue: GPIO 33

The button is connected to GPIO 14.

The goal is to build a webpage connected to a local server. When the physical button is pressed, something happens on the webpage.

The proposed experience is:
- The webpage asks the visitor to enter one character.
- On one button press, the screen shows a red burst like a firework.
- On two button presses, blue comes from the left and green comes from the right.
- The blue and green meet in the middle and create an explosion.
- The explosion reveals a realistic red apple with the visitor's character embossed in the center.

This is a documentation-only design project. The implementation will use the agreed HTML, CSS, JavaScript, and C++ technologies, without providing source code in these planning documents.
